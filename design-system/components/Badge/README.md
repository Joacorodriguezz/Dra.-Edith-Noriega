Etiqueta corta en mayúsculas para especialidad, tipo de caso o estado. Variantes: `en-badge--brand`, `en-badge--aqua` y `en-badge--soon` (borde punteado).

- Una o dos palabras. No lleva enlace ni acción.
- `en-badge--soon` con el texto "Próximamente" marca lo que todavía no está disponible, como Posturología.
- No mezcles más de tres badges en una tarjeta.
