Contacto por consultorio (La Plata y Quilmes) y formulario. El consumidor aporta la dirección, los horarios y el enlace de WhatsApp de cada sede.

- Cada sede tiene su botón `en-btn--aqua` "Pedí tu turno por WhatsApp". Un enlace `tel:` o `https://wa.me/` puede no abrir en todos los entornos: mostrá también el número como texto.
- Campos con etiqueta visible (`en-field`). El error explica qué corregir: "Escribí un número de WhatsApp completo, con característica."
- Agregá `aria-invalid="true"` y `aria-describedby` al campo con error.
- Pedí solo nombre, WhatsApp y motivo.
